# DICE HAND — 戦闘デモ

手札に並ぶダイス目の組み合わせで役を作る、1対1ターン制カードバトルのブラウザデモです。

## 起動

Node.js 18以降を用意し、プロジェクトのルートで実行します。

```bash
npm run dev
```

ブラウザで [http://localhost:4173](http://localhost:4173) を開いてください。外部ライブラリのインストールは不要です。

## テスト

```bash
npm test
```

役判定、常在能力、次ターン効果、ダメージ計算、デッキ構成、ターン進行をテストします。

## 主な構成

- `src/data`: 定数、カード、役データ
- `src/game`: デッキ、役、能力、ダメージ、戦闘進行ロジック
- `src/app.js`: 画面描画と操作
- `src/styles.css`: レスポンシブUIと戦闘演出
- `test`: ロジックの単体テスト
